#01 Получить Telegram Token
1
Создать бота через @BotFather Telegram
Открой Telegram → найди @BotFather → отправь команду:
chat с @BotFather 
/newbot
BotFather спросит:
1. Имя бота (например: InfoSearch Поиск)
2. Username (например: infosearch_kz_bot) — должен заканчиваться на _bot
💡
BotFather пришлёт сообщение с токеном вида: 7123456789:AAHabc... — это твой TELEGRAM_TOKEN
2
Настроить бота в BotFather
Дополнительно отправь команды:
chat с @BotFather 
# Установить описание бота
/setdescription
→ 🔍 Поиск людей по открытым базам данных. Оплата только после проверки. Законно.

# Установить фото профиля
/setuserpic
→ отправь любое изображение (логотип или иконку лупы)

# Установить команды меню
/setcommands
→ start - Главное меню
reset - Сбросить диалог
#02 Получить Anthropic API Key
3
Зарегистрироваться на Anthropic API
1. Перейди на console.anthropic.com
2. Зарегистрируйся (Google / email)
3. Слева → API Keys → Create Key
4. Скопируй ключ — он начинается с sk-ant-...
⚠️
Ключ показывается только один раз — сохрани сразу! Пополни баланс: минимум $5. Стоимость ~$0.001 за диалог — хватит надолго.
#03 Узнать свой Telegram ID
4
Получить OPERATOR_ID Твой ID
Это твой личный ID — бот будет присылать уведомления о новых клиентах именно тебе.
Telegram 
# Напиши боту:
@userinfobot

# Он ответит что-то вроде:
Id: 123456789
First: Иван
...
💡
Число после Id: — это твой OPERATOR_ID. Вставь его в bot.py.
#04 Настроить bot.py
5
Вставить токены в файл bot.py
Открой bot.py и замени 3 строки в самом начале:
bot.py — строки 9–11 
TELEGRAM_TOKEN    = "7123456789:AAHabc..."   # от @BotFather
ANTHROPIC_API_KEY = "sk-ant-api03-..."       # от console.anthropic.com
OPERATOR_ID       = 123456789                  # твой Telegram ID
✅
Также замени в тексте сообщений платёжные реквизиты — ищи +7 XXX XXX XX XX и TВашАдресКошелька
#05 Установить и запустить
6
Установить Python и зависимости Терминал
Нужен Python 3.10+. Скачай на python.org если нет.
Терминал / CMD 
# Перейди в папку с ботом
cd путь/к/папке/с/ботом

# Установи зависимости
pip install -r requirements.txt

# Запусти бота
python bot.py
🚀
Если в консоли появилось InfoSearch Bot запущен! — всё работает. Напиши боту /start в Telegram.
7
Чтобы бот работал 24/7 Хостинг
Пока бот запущен на твоём компьютере — он работает только когда он включён.
Для постоянной работы нужен сервер. Варианты:
⭐
Railway.app (рекомендую) — бесплатно до $5/мес, деплой за 5 минут
1. Зарегистрируйся на railway.app
2. New Project → Deploy from GitHub (загрузи папку с ботом)
3. Добавь переменные: TELEGRAM_TOKEN, ANTHROPIC_API_KEY, OPERATOR_ID
4. Deploy — готово!
💡
Альтернатива — VPS у reg.ru / timeweb / beget от 200₽/мес. Подключаешься по SSH и запускаешь: nohup python bot.py &
#06 Как работать с ботом
8
Как ты получаешь заказы
Когда клиент скажет что готов платить — ты получишь уведомление:
Сообщение тебе в Telegram 
🔔 НОВЫЙ КЛИЕНТ ГОТОВ К ОПЛАТЕ

👤 Имя: Иван Иванов
📱 Username: @ivan_user
🆔 ID: 123456789

💬 Последние сообщения:
👤 Клиент: Ищу данные по номеру...
🤖 Бот: Нашёл совпадения, стоимость...
Чтобы ответить клиенту напрямую — используй команду:
Пишешь боту 
# Формат:
/reply 123456789 Привет! Оплатите на этот кошелёк USDT...

# Клиент получит:
👨‍💼 Оператор:
Привет! Оплатите на этот кошелёк USDT...
